Key Features

  • Vehicle fleet management & tracking: Available, Rented, Maintenance, Reserved.
  • Customer & manager management: New customer registration with automated ID generation.
  • Rental operations: Due-date calculation based on a strict 14-day rental period.
  • Return operations: Automatic late-fee calculation at 150 EGP per day.
  • Data validation & lookup: Customer and vehicle lookup by ID, regex-based email and phone validation.
  • Error resilience: Comprehensive exception handling using structured try-catch blocks.

OOP Implementation

  • Inheritance: Manager and Customer inherit from the abstract User class.
  • Abstraction: The User class provides a common foundational base for registered system users.
  • Encapsulation: Customer and vehicle collections are protected within the Branch class using private fields.
  • Polymorphism: Class structures designed to support extensibility and specialized user behaviors.
